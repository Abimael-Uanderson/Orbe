# Checklist de qualidade

## Antes de cada entrega

- [ ] `npm run check` sem erros ou avisos.
- [ ] `npm test` concluído.
- [ ] `npm run build` concluído.
- [ ] Tema claro revisado.
- [ ] Tema escuro revisado.
- [ ] Navegação por teclado conferida.
- [ ] Foco visível nos controles.
- [ ] Estados vazio, erro, sucesso e carregamento considerados.
- [ ] Desktop sem rolagem desnecessária.
- [ ] Mobile sem corte de conteúdo ou scroll horizontal.
- [ ] Nenhum dado sensível real nos mocks.
- [ ] Nenhuma exclusão física em ações de interface.

## Fluxos críticos

- [ ] Login de paciente, funcionário e administrador.
- [ ] Novo agendamento e comprovante.
- [ ] Check-in e evolução da fila.
- [ ] Registro de aplicação.
- [ ] Baixa automática do lote.
- [ ] Evento de auditoria.
- [ ] CRUDs administrativos.
- [ ] Restauração dos dados de demonstração.
